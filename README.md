OSINT Guard Bot

Telegram-бот для OSINT анализа доменов, телефонных номеров и BIN банковских карт с интеллектуальной системой оценки рисков.

OSINT Guard Bot - это автоматизированный инструмент для проверки безопасности и анализа рисков на основе открытых источников информации (OSINT). Бот выполняет комплексную проверку доменов, телефонных номеров и BIN кодов банковских карт, предоставляя детальную оценку рисков по шкале 0-10 с понятными объяснениями.

Ключевые особенности:
- Unified Risk Scoring** - единая система оценки 0-10 для всех типов проверок
- Explainability** - детальное объяснение каждого балла риска
- Визуальная индикация - цветовое обозначение уровня риска
- Retry механизм - автоматические повторные попытки при ошибках API
- Подробное логирование - полная история всех операций

Что умеет бот

Domain Scanner (/scan <домен>)

Проверяет:
- Возраст домена (новые домены < 30 дней = высокий риск)
- WHOIS информацию и privacy protection
- DNS конфигурацию (Cloudflare-only, нестандартные NS)
- SSL сертификаты (возраст, количество доменов)
- Robots.txt сигнатуры
- IP reputation (proxy/VPN, страны высокого риска)
- Доверенные провайдеры (Google, Cloudflare, Amazon)

Пример вывода:

🟢 Сканирование домена: google.com
Итоговый риск: Низкий (1/10)

Основные признаки:
  🟢 (-4) Домен существует 27 лет (высокое доверие)
  🟢 (-3) Хостинг у доверенного провайдера: Google
  🟢 (-2) SSL сертификат покрывает 15 доменов



Phone Scanner (/phone <номер>)

Проверяет:
- Страну по номеру
- Оператора связи (через Veriphone API)
- Регион номера
- Тип номера (mobile/landline/voip)
- Валидность номера
- Уровень уверенности определения (0-100%)



Нормализация номеров:
- +79991234567 → 79991234567
- 89991234567 → 79991234567
- 9991234567` → 79991234567

Пример вывода:

🟢 Проверка телефона: +79991234567
Итоговый риск: Низкий (1/10)
Уверенность: 95%
Страна: RU
Оператор: МТС
  ⚠️ Виртуальный оператор (MVNO) — возможен MNP
Регион: Москва



BIN Scanner (/bin <6-8 цифр>)

Проверяет:
- Платёжную систему (Visa/Mastercard/МИР)
- Тип карты (debit/credit/prepaid)
- Банк-эмитент
- Страну выпуска
- Prepaid карты (+3 риска)
- Доверенные банки (Сбербанк, ВТБ, Тинькофф: -2 риска)

Пример вывода:

🟢 Проверка BIN: 427229
Итоговый риск: Низкий (2/10)

Данные по BIN:
  Схема: visa
  Банк: Sberbank
  ✅ Доверенный банк
  Страна: Russia (RU)

Детализация рисков:
  🟢 (-2) Карта выпущена доверенным банком: Sberbank



Инструкция по запуску

Предварительные требования

- Python 3.11
- Telegram Bot Token

2. Установка

- Клонируйте репозиторий
cd e:\MyProjects\osint_guard_bot

- Установите зависимости
pip install -r requirements.txt

Конфигурация

Создайте файл .env в корне проекта:
BOT_TOKEN=your_telegram_bot_token_here
VERIPHONE_API_KEY=your_veriphone_api_key_here (я использовал этот бесплатный сервис в качестве примера. На бесплатном тарифе 1000 запросов/сутки лимит. В идеале перейти на платные API, что бы более информативным сделать бота.)
Пример .env.example уже есть в проекте.

- Запуск бота
python main.py

INFO | Bot starting polling... - будет сигнализировать об успешном запуске.

Переходитье к тестированию

Откройте Telegram, найдите вашего бота и отправьте команды:

Конфигурация и настройка

Настройка retry параметров

В файлах services/*.py можно изменить параметры повторных попыток:

@retry_async(max_attempts=3, backoff=2, exceptions=(Exception,))
Где:
- max_attempts - максимальное количество попыток
- backoff - коэффициент экспоненциального отката (в секундах)

Настройка доверенных банков

Отредактируйте bin_scanner/trusted_bins.py:

TRUSTED_BANKS_RU = {
    "sberbank",
    "vtb",
    "tinkoff",
    добавляйте свои
}


Настройка rate limiting

В middlewares/rate_limit.py измените интервал:
RateLimitMiddleware(min_interval_seconds=10)  # 10 секунд между запросами



Система оценки рисков

Шкала 0-10

- 0-3 Низкий риск - явных признаков угроз нет
- 4-6 Средний риск - обнаружены подозрительные признаки
- 7-10 Высокий риск - серьёзные признаки недобросовестности



Далее, что хотелось бы видеть во всем этом, что бы бот был максимально полезным на сколько это возможно (aka амбициозный список):

1. Email Scanner
- Проверка существования email через SMTP
- Disposable email detection (temp-mail.org, guerrillamail и т.д.) - определять одноразовые email.
- Email reputation check - проверять, не засвечен ли этот email в спам базах или базах утечек данных.
- Domain age - проверять возраст домена + MX records анализ.
- Spam trap detection - определять email-ловушки, которые используют для отлова спамеров.
- Risk scoring для email - итоговая оценка риска 0-10.


2. IP Scanner
- IP geolocation (страна, город, ISP) - определять страну, город, провайдера (ISP) по IP.
- VPN/Proxy/Tor detection - определять, используется ли VPN, прокси или Tor (анонимайзеры = повышенный риск).
- IP reputation - проверять IP в blacklists, abuse reports.
- ASN информация - Autonomous System Number - показывать, какой организации принадлежит этот IP-блок.
- Hosting provider detection - определять хостинг-провайдера (AWS, DigitalOcean, VPS и т.д.
- Risk scoring для IP - формируем итоговую оценку из вышеуказанных показателей 0-10

3. Crypto Wallet Scanner
- Bitcoin/Ethereum/USDT/Solana - поддержка как минимум основных криптовалют
- Balance check - проверять баланс
- Transaction history - показывать историю транзакций
- Known scam addresses detection - проверять в базах известных мошеннических адресов
- Mixer/tumbler usage - определять использовались ли миксеры
- Risk scoring для крипто-адресов - тоже по полученным данным отображать оценку надежности 0-10.


4. Social Media Scanner
- Username lookup across platforms (Instagram, Twitter, Telegram, VK) - поиск по имени во всех соц.сетях
- Account age detection - определять возраст аккаунта
- Activity patterns - паттерны активности
- Fake account indicators - узнавать признаки фейковых аккаунтов.
- Risk scoring для соц. сетей - система баллов. 


5. Advanced Features (это уже если делать для большого количества пользователей):

- Экспорт отчётов (PDF/JSON/CSV)

- Webhooks для интеграции с другими системами
- API endpoint для внешних сервисов
- Multi-user support с ролями
